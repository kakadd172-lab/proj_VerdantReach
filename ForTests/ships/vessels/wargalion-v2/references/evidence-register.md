# Wargalion V2 evidence register

| Subject | Evidence | Status | Modelling treatment |
|---|---|---|---|
| Historical reference | San Martín / São Martinho, Portuguese-built galleon later in Spanish service | Identified in naval-periodical and secondary accounts | Reference label only; this is not an exact replica |
| Principal dimensions | 39.0 × 11.7 m in Revista General de Marina (2007) | Published account of a model | Working scene scale |
| Alternative dimensions | 35.3 × 10.5 m in a later secondary account | Conflicting secondary report | Preserved as alternative evidence |
| Hull profile | Reproduced San Martín plan sheet | Secondary reproduced plan, not a calibrated original offsets table | Profile and sections are qualitative guides; station values remain reconstruction estimates |
| Hull shape context | Portuguese 16th-century rising-and-narrowing research | Peer-reviewed general method research | Context only; not proof that this exact ship used one prescribed procedure |
| Comparative plans | Pinterest side, deck and frame drawings of other galleons | General comparative imagery, not San Martín-specific | Used to compare broad profile, plan-view taper and sectional fullness only |
| Aftercastle | Reproduced model plan and comparative historic galleon imagery | Comparative reconstruction evidence | Three stepped deck levels and galleries remain a visual hypothesis |
| Exact rig | No calibrated rig drawing has been transcribed for this build | Unresolved | Deferred from this stage |

## Required before historical calibration

1. Obtain a higher-resolution plan with traceable scale marks.
2. Record pixel-to-metre calibration and uncertainty for every digitized station.
3. Cross-check body-plan sections against waterline and buttock families from the common surface.
4. Compare stern and forecastle profiles against attributable period evidence.
5. Revisit principal dimensions if stronger primary evidence becomes available.
