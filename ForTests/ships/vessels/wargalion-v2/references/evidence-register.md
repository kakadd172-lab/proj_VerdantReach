# Wargalion V2 evidence register

| Subject | Evidence | Status | Modelling treatment |
|---|---|---|---|
| Historical reference | San Martín / São Martinho, Portuguese-built galleon later in Spanish service | Strong identification in secondary and naval-periodical accounts | Reference label only; do not claim an exact replica |
| Principal dimensions | 39.0 × 11.7 m in Revista General de Marina (2007) | Published account; model dimensions | Working scene scale |
| Alternative dimensions | 35.3 × 10.5 m in a later secondary account | Conflicting secondary report | Preserve as alternative evidence |
| Hull offsets | Reproduced San Martín plan sheet | Secondary plan reproduction, not a calibrated original offsets table | Current station values remain visual reconstruction estimates |
| Construction context | Portuguese 16th-century rising-and-narrowing research | Peer-reviewed general method research | Contextual guide for turn-of-bilge study, not proof of this vessel's exact method |
| Cabin profile | Contemporary galleon depictions and reproduced model plan | Comparative / secondary evidence | Three stepped polygonal cabin tiers are a first geometry hypothesis |
| Exact rig | No verified attributable rig plan digitized for this model | Unresolved | Excluded from this stage |

## Required before calling the model historically calibrated

1. Obtain a higher-resolution plan with identifiable scale marks and trace its profile and transverse sections.
2. Record calibration method, pixel-to-metre conversion, and each digitized station's uncertainty.
3. Cross-check every station against the waterline and buttock families derived from the common surface.
4. Compare cabin tier count, widths, windows and galleries against attributable period evidence.
5. Revisit the working dimensions if a more authoritative measurement becomes available.
