Imported models & local files

Load your own GLB/glTF model here. Imported meshes keep their materials and become selectable editor components. Historical source candidates are documented separately; external links are not bundled presets.

Local imports appear in the vessel selector after you load a GLB/glTF file.

A GLB is usually self-contained. For a glTF file with external textures or .bin data, select all related files together or choose the extracted model folder. Local files are not uploaded to GitHub; re-import them after restarting the browser.

Import & export

Import accepts this editor's exported JSON or a saved design-overrides.json file. It does not modify the base vessel modules.
