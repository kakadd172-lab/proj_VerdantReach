Historical ship model research

← Back to Shipyard Studio

This page is an inspection shortlist, not a list of imported assets. The two 3D viewers below are real, downloadable model pages whose ship types can be identified, but their stated historical contexts are earlier than the project's 1600s–1800s target. They are useful for comparing vessel forms only; neither is currently a production-ready period match.

Nothing on this page is bundled into the game yet. A 3D viewer or source page is not the same thing as a local GLB/glTF file. The modern yacht, fishing trawler and motor cruiser demo presets have been removed from the editor. The local GLB/glTF import tool remains available.

Portuguese Caravel

Ginny Sutton's model is explicitly based on a 15th-century Portuguese caravel. It is a type-specific reference, but it predates the 1600s–1800s setting, so it is not being accepted as the final in-period caravel asset.

Chinese Merchant Junk

Nisa Nurul Azizah's model is described as a Chinese merchant junk travelling to Sumatra during the Sriwijaya period. It is a useful junk-type reference, but its stated context is earlier than the requested Age-of-Sail period.
