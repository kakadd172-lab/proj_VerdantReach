# War Galleon II — runtime vessel

A separate, editable runtime vessel registered in Verdant Reach's game ship catalogue.
This is a composite late-sixteenth-century galleon reconstruction, not a claimed replica
of one named surviving vessel or a traced lines plan.

- Principal design envelope: 38.0 m length, 10.6 m beam, 4.7 m draft.
- Three-mast arrangement: square fore and main masts, lateen mizzen, bowsprit and headsails.
- Independent hull equations, mast stations, architecture layout, editor defaults and
  local component-generator copies are kept in this folder.
- Existing Galleon and the standalone ForTests War Galleon remain unchanged.
